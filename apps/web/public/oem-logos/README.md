# DiagNova – originale Fahrzeugherstellerlogos

Enthalten: 38 Marken aus der bisherigen DiagNova-Liste.

- `logos/`: unveränderte Originaldateien aus dem hochgeladenen Repository (SVG/PNG).
- `tiles/light` und `tiles/dark`: 512 × 384 PNG mit originalem Emblem auf weißer Fläche. Weiß ist bewusst auch im Dark Mode gewählt, weil die Quelle für weiße Hintergründe optimiert ist.
- `brands.json`: Zuordnung zu DiagNova-Marken-IDs.

Quelle: vom Nutzer bereitgestelltes Archiv `brand-logos-main.zip` (vehiclespecs/brand-logos).
